# MERIDIAN

Luxury watch product visualization — GLTF model, hotspots, live configurator (case / strap / dial).

```bash
npm install
npm run build:model   # regenerates public/models/meridian-watch.glb
npm run dev
```

Deploy (GitHub Pages base `/mdb-brasa/`):

```bash
npm run deploy
```
